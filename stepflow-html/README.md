# StepFlow｜一步流

一个使用 HTML、Tailwind CSS 与原生 JavaScript 制作的 StepFlow V0.1 交互原型。

## 项目内容

- `index.html`：页面结构、Tailwind 主题与响应式布局
- `app.js`：导航、任务执行、计时、临时任务和复盘交互
- `mist-paper.jpg`：原创雾绿色纸张纹理背景

## 预览方式

直接双击 `index.html` 即可查看页面。为了获得自动刷新预览，也可以在本目录启动任意静态网页服务器。

页面会从 CDN 加载 Tailwind CSS 和 Lucide 图标，因此首次打开时需要网络连接。

## 已实现页面

- 今日：AI 建议、执行顺序、正常版与最低可行版、专注计时、完成反馈
- 任务池：自然语言收集、AI 拆解、时间估算与异议反馈
- 我的进度：项目进度、里程碑、近七天推进和 AI 观察
- 全局交互：临时任务、今日状态调整、排序解释、晚间复盘
